# MiniShop - Sample E-Commerce Website

A beginner-friendly sample store built with HTML, CSS, Python Flask, and SQLite.

## Features
- Product catalog
- Register and login
- Demo admin role
- Place sample orders
- View order history and status
- Admin can add products and view orders
- SQLite database created automatically

## Run locally
1. Install Python 3.
2. Create and activate a virtual environment.
3. Install dependencies: `pip install -r requirements.txt`
4. Start the app: `python app.py`
5. Open http://127.0.0.1:5000

## Demo admin

- Password: `admin123`

## Important
This is an educational demo only. Passwords are stored as plain text and the secret key is for local testing. Do not deploy as-is or use real customer data. Use password hashing, environment-based secrets, CSRF protection, and production settings before public deployment.
